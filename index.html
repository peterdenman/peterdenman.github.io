First-time setup
  1. In Anki: Tools → Add-ons → Get Add-ons, enter code 2055492159 (AnkiConnect), then restart Anki.
  2. Keep Anki open and use this page in Chrome, Edge or Firefox on the same computer.
  3. Open this page with Anki running. The first time, Anki shows a permission popup for this site; click Yes. After that the page connects and syncs by itself every time you open it (and again if you come back after 15+ minutes). If the browser asks to let the page access devices on your local network, allow it.
  4. Still blocked? In Anki open Tools → Add-ons → AnkiConnect → Config and add your site's address (e.g. https://username.github.io) to webCorsOriginList, then restart Anki.
  5. For one-click AMBOSS practice, install the AMBOSS Anki add-on. The notebook's Start Qbank session button opens your weak cards in Anki's Browse window, where the add-on turns them into a matching Qbank session.
  6. After each analysis, results sync to GitHub, so your phone shows the latest snapshot even without Anki.
